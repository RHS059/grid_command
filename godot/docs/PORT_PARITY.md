## Verification

Godot4.7.2 headless scene smoke passes with `GRID_COMMAND_UPDATE_SMOKE_OK` and `GRID_COMMAND_SMOKE_OK`. Assertions cover role costs, /100 infantry movement, stationary commands, both-side procurement, delayed supply, shared scene/core records, dismounted capture, RED victory, pause-preserving speed, single step, complete session restore, legal timed carrier transitions and launch cooldown, transport overbooking and completed dismount cleanup, 24-seat landing craft, repair stock consumption, and geographic orientation. `GRID_COMMAND_GAMEPLAY_CORE_SMOKE_OK` covers exact weapon contracts, AA lock/impact, suppression/casualties, capture/victory, command succession, medic/ammo support, carrier-loss recovery, jammer construction, crew dismount and fuel-economy admission. `GRID_COMMAND_COMMANDER_DIRECTOR_SMOKE_OK` covers delayed imperfect-information contacts and objective reports, simultaneous planning, formations, missions, council state and restore. `GRID_COMMAND_MARITIME_NAVIGATION_SMOKE_OK` covers deterministic water-only travel, dry/disconnected rejection, route retention, recovery fuel and amphibious shore links. `GRID_COMMAND_CAMERA_FOLLOW_SMOKE_OK` covers browser gestures, rear chase, embarked following and presentation interpolation. `GRID_COMMAND_TACTICAL_HUD_SMOKE_OK` covers contextual boarding, passenger and crew dismount exposure, jammer command exposure, contact-channel compatibility, scrolling force roster, read-only observer command presentation, live commander council reports and the terminal operation banner. Global integration assertions cover active streaming, installation exclusions, duplicate terrain suppression, attribution, Mercator bounds and Paris camera navigation without clamping back to San Diego. Rendered OpenGL captures verify the floating HUD and source APC/cannon APC/FQ-44/carrier textures, plus actual vector geography at overview/detail zooms and the global navigation drawer. `git diff --check` is also run before handoff.

The geographic project settings enable online tile streaming and a bounded disk cache by default. `geography/tls_ca_bundle` is empty by default so the HTTP layer can select its system-trust path; an explicitly configured existing CA bundle is forwarded unchanged. Main-scene smoke disables network access for deterministic checks against the bundled warm cache. The orbit camera scales its near clip plane with distance to preserve depth separation between flat map surfaces at overview zoom.

The remaining gaps above are intentional disclosures. A green smoke run establishes these tested contracts, not equivalence of all browser subsystems or a performance benchmark.
