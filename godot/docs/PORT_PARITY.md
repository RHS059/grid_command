## Verification

Godot4.7.2 headless scene smoke passes with `GRID_COMMAND_UPDATE_SMOKE_OK` and `GRID_COMMAND_SMOKE_OK`. Assertions cover role costs, /100 infantry movement, stationary commands, both-side procurement, delayed supply, shared scene/core records, dismounted capture, RED victory, pause-preserving speed, single step, complete session restore, legal timed carrier transitions and launch cooldown, transport overbooking and completed dismount cleanup, 24-seat landing craft, repair stock consumption, and geographic orientation. Global integration assertions cover active streaming, installation exclusions, duplicate terrain suppression, attribution, Mercator bounds and Paris camera navigation without clamping back to San Diego. Rendered OpenGL captures verify the floating HUD and source APC/cannon APC/FQ-44/carrier textures, plus actual vector geography at overview/detail zooms and the global navigation drawer. `git diff --check` is also run before handoff.

The geographic project settings enable online tile streaming and a bounded disk cache by default. `geography/tls_ca_bundle` is empty by default so the HTTP layer can select its system-trust path; an explicitly configured existing CA bundle is forwarded unchanged. Main-scene smoke disables network access for deterministic checks against the bundled warm cache. The orbit camera scales its near clip plane with distance to preserve depth separation between flat map surfaces at overview zoom.

The remaining gaps above are intentional disclosures. A green smoke run establishes these tested contracts, not equivalence of all browser subsystems or a performance benchmark.
