# FQ-44 generated contour guides

These two images were generated from the five supplied photographs to support a contour-based Blender blockout.

- `fq44_side_ortho_generated.png` is the side contour aid.
- `fq44_front_ortho_generated.png` is the front contour aid.

The original photographs are authoritative. The guides can contain invented panel lines, mechanisms, and hidden structure. Use them for the outer contour and shared landmarks only after comparison with the photographs. Do not treat them as measured drawings.

The first generated top views were rejected because they misread the vertical tail. They are not modeling references and are not included here.
